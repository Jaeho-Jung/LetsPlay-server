## 실제 음성·LLM 검사

macOS ARM64, CPU FP32. 프로젝트의 CTranslate2 아동 음성 Whisper-small 가중치를 사용했습니다. 샘플의 화자 연령은 확인하지 않았으며 아동 사용자 테스트로 부르지 않습니다.
공개 샘플에서 추출한 전사문을 OpenAI로 전송하는 데 대한 사용자 허용을 받은 후 실행했습니다. API 키는 자료에 포함하지 않았습니다.

| 샘플 | 오디오 길이(초) | 기존 문장/질문/글자 | 1차 수정 문장/질문/글자 | 최종 문장/질문/글자 | 최종 완료(초) |
|---|---:|---|---|---|---:|
| sample_input_0.wav | 3.1625 | 8/5/238 | 3/2/50 | 2/1/38 | 6.73 |
| sample_input_1.wav | 9.2375 | 8/3/278 | 2/1/47 | 2/1/32 | 7.38 |
| sample_input_2.wav | 1.6875 | 4/2/77 | 2/1/28 | 2/1/31 | 8.40 |

글자 수는 LLM 문장들을 공백으로 연결한 문자열 길이이며, 문장 수는 스트리밍 파서가 반환한 문장 수입니다. 질문 수는 물음표 개수입니다. 기존·최종 응답은 독립 연결에서 같은 WAV를 전사해 생성했습니다.

최종 프롬프트는 모든 관찰 샘플에서 두 문장·질문 하나·90자 이내를 충족했습니다. 수정에 사용한 동일 3개 입력이므로 미지 입력 일반화, 교육 효과 또는 전체 응답 품질 개선을 입증하지 않습니다.

완료 시간은 첫 전송부터 END 수신까지의 로컬 관찰값으로 모델 로딩을 제외합니다. 공인 서버 지연이나 클라이언트 재생 시간은 아닙니다. API 응답 길이·네트워크·워밍업·동시 실행 조건이 달라 기존 수치와 속도 개선 배수를 계산하지 않습니다.

정답 전사문이 없어 WER/CER을 계산하지 않았고, PCM 바이트 수신만 검사해 음질·자연스러움은 평가하지 않았습니다. 긴 샘플의 전사에 어색한 표현이 관찰되어 정확도 검증은 별도로 필요합니다.

음성 전사문과 생성 답변 원문은 공개하지 않고 검증 지표만 보존했습니다.

## 재현 보강

1. 정의되지 않은 utils import와 실제 모델 디렉터리 이름을 수정했습니다.
2. WebSocket의 WAV bytes를 BytesIO로 전달하도록 수정했습니다.
3. 누락된 CTranslate2 vocabulary.json을 동일 tokenizer의 연속 ID 순서로 복원하는 스크립트를 추가했습니다.
4. faster-whisper 의존성을 추가했습니다. PyAV 19.0.2에서 metadata_errors 인수 오류를 재현했고 18.1.0에서 정상 디코딩을 확인해 av<19 범위를 설정했습니다.
5. 연결별 대화 컨텍스트를 분리하고, 종료 시 정리하며 초기화 API는 활성 대화를 모두 초기화하도록 유지했습니다.
6. GPTService의 두 번째 인스턴스 초기화와 max_tokens 전달을 수정했습니다.
7. 시연 클라이언트가 10청크 미만의 짧은 응답도 재생하도록 수정했습니다.
8. 역할놀이 시스템 프롬프트를 짧은 호응 문장과 질문 하나로 구성하도록 수정했습니다.

모델 가중치 재학습이나 인식 정확도 개선은 수행하지 않았습니다. Cloud Run 재배포·앱 음성 재생·실사용자 검사는 이번 범위에 포함하지 않았습니다.
